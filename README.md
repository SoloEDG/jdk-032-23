# 骨牌造境

## 本地启动

```sh
npm ci
npm run dev
```

在浏览器打开 Vite 输出的本地地址。

## Docker 启动

```sh
docker compose up --build
```

打开 <http://localhost:8032>。端口可通过 `DOMINO_LAB_PORT` 修改。

## 测试

```sh
npm test
```

测试基于 Node 内置测试运行器（TypeScript 原生剥离），覆盖复位滚轮的核心规则。

## 复位滚轮

连锁倒下后不再需要从头重摆：首轮结束后，一只复位滚轮沿桌面支路出发，把骨牌
推回站立以便继续练下一轮。

### 接触规则

- 只有滚轮进入接触半径、且骨牌仍处倒下（露出**复位面**）时，才会推回站立并记录
  `reset` 事件；站立的骨牌不会被误触，只会登记在“路过未倒”清单。
- 接触判定基于滚轮行驶路径段到骨牌的最近距离，固定步长采样不会跨过接触窗口。

### 两支路交替

- 滚轮配置包含两条支路，每个循环在支路 A / B 之间交替；去程走到支路末端后原路回程。
- 全部骨牌复位后第二轮连锁自动启动；仍有骨牌未复位时第二轮不启动。

### 按轮次记录

- 每个事件带 `round` 字段：第二轮再次倒下的骨牌产生**新的事件**（新 id、新时间、
  `round: 2`），首轮事件原样保留，绝不覆盖。
- 回放支持按轮次筛选，骨牌颜色随回放时间在站立 / 倒下 / 已复位之间变化，滚轮沿
  实际轨迹播放并标注去程、回程。

### 异常与现场保留

- **卡在坡道**：坡面摩擦系数过低时滚轮打滑卡住，报告已复位与未复位清单，第二轮跳过。
- **机关提前关闭**：滚轮经过触发器时机关连线关闭并截停滚轮，现场保留。
- **支路无法覆盖**：循环达到上限仍有骨牌未复位时标记 `unreachable`，同样保留现场。
- 每次“运行模拟”都是独立运行：事件 id 带运行前缀，重复启动不会复制同一轮记录。
